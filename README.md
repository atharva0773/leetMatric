## 🧩 Project Overview  
Leet Matrix is a React-based dashboard designed to help developers track and visualize their coding progress on platforms like LeetCode.  
It fetches data from the LeetCode API and provides streak analytics, badges and charts to keep users motivated.

---

## ✨ Features  
- ✅ LeetCode API integration — automatically fetch problem stats  
- 📊 Dashboard layout with charts & badges  
- 🔥 Streak analysis of coding activity  
- 🎨 Styled with Tailwind CSS for quick, modern UI  
- 📱 Fully responsive design  
- ⚡ Built with performance and best-practices in mind
